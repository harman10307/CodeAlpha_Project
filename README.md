# CodeAlpha_Project
In Project1 I have made a simple text based Hangman game where a player guesses a word one letter at a time.
In this I have used the key concepts : random, while loop, if-else, strings, lists
In Project2 I have build simple stock tracker that calculates total investment based on manually defined stock prices.
In this I have used the key concepts : dictionary, input/output, basic arithmetic.
In Project3 I have build a simple ruled based chatbot.
In this I have used the key concepts: if-elif, functions loops, input/output
